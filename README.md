A [six degrees of separtion](https://en.wikipedia.org/wiki/Six_degrees_of_separation) thing for Spotify.

A connection is counted as a collab between two artists. I start from an artist (say Bruno Mars), find all of his collabs, store the conenctions in a graph. Then do the same for each of his collabs, and so on for however many levels down I decide.

For Bruno Mars, going to 3 degrees of separation, the graph reaches 49,637 nodes and 117,841 edges, which shows how interconnected artists are.
